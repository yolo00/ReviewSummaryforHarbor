ANALISIS SENTIMEN PELABUHAN FERRY BATAM

FerryPulse menganalisis ulasan penumpang pada lima pelabuhan ferry di Batam menggunakan model Support Vector Machine (SVM) untuk memahami sentimen penumpang terhadap kebersihan, fasilitas, pelayanan, antrian, harga, keamanan, akses, serta jadwal kapal.

Mulai Analisis
Analisis Sentimen

Mengklasifikasikan ulasan menjadi positif, netral, dan negatif dengan model SVM.

Visualisasi Data

Menampilkan tren sentimen, popularitas pelabuhan, wordcloud, dan heatmap aspek.

Update Real Time

Data ulasan dan hasil prediksi dapat diperbarui melalui pipeline otomatis.
